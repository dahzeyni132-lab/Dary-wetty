# داري وسيارتي — نسخة أولية

تطبيق Expo/React Native عربي يعمل على Android وiPhone.

## التشغيل
1. ثبّت Node.js وExpo.
2. داخل المجلد شغّل:
   npm install
   npx expo start
3. افتح QR عبر Expo Go، أو شغّل Android/iOS من بيئة التطوير.

هذه النسخة Prototype: البيانات تجريبية ومخزنة داخل التطبيق. لاحقًا يمكن ربطها بقاعدة بيانات، تسجيل دخول، رفع الصور، الخرائط، المحادثات والإشعارات.
